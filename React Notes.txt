Props :- Props (short for "properties") are how data is passed from a parent React component to a child component. They are similar to function arguments. Props are read-only inside child components — you cannot modify them there.

Example:

jsx
function Greeting(props) {
  return <h1>Hello, {props.name}!</h1>;
}

// Usage:
<Greeting name="Alice" />
