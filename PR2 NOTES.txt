	       --- Promise ---

			1. It is a Special JS Object that represent a task that will finish in the future either Successful or with an error.
			    
			2. It is the solution to callback hell problem. 
			
			3. There are 3 states for Promise Object 

				1. Pending :- It is Displayed in the Initial State. 

				2. fulfilled :- When the Fetching Data is UnSuccessful then it is Rejected

				3. Rejected :- When the Fetching Data is UnSuccessful then it is Rejected
	
			4. Eg -  

	 <script>
        let obj = new Promise((resolve, reject) => {
            resolve("Promise started");
            reject("Promise failed");
        });
        obj.then((message) => {
 	           console.log(message);
        }).catch((error) => {
            console.error("Error:", error);
        });

    </script>


	  --- ASYNCHRONOUS OPERACTION ---
			
			 	
			
			1. then() :- this Function is called when the object change its state from pending to fulfilled.
					it is link resolve 

			2. catch() :- It is linked with the Reject.
			
			          E.g :- 
						   
	<script>
        console.log("1");
        console.log("2");
        console.log("3");
        let obj = new Promise((resolve, reject) => {
            
            setTimeout(() => {
                resolve("4");
                reject("Network Error");
            }, 3000);
        });
        obj.then((message) => {
            console.log(message);
        }).catch((error) => {
            console.error("Error:", error);
        }).catch((x)=>{
            console.error("Another Error:", x);
        })

    </script>
